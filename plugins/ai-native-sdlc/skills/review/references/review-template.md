# REVIEW.md

このリポジトリの PR レビュー方針。Claude による自動レビューと人間レビューの両方がこれに従う。AI の指摘は承認ではない。マージ承認はコードオーナーが行う。

## レビューパス

1. **バグ**: ロジック、境界条件、エラー処理、並行性、既存挙動の破壊
2. **セキュリティ**: 入力検証、認可、秘密情報、インジェクション、新規依存
3. **コンプライアンス**: <組織ポリシー / スキル名を列挙>
4. **仕様**: 対応する spec.md の受け入れ条件との整合

## Important(マージを止める)

- 本番でユーザーに見える誤動作を起こしうるもの
- データ損失・破損・漏えいにつながるもの
- 認可のバイパス、秘密情報の混入
- 受け入れ条件を満たしていないもの
- テストが無い、またはテストが実質何も検証していない振る舞い変更
- <プロジェクト固有の項目>

## Nit(止めない)

- 命名、軽微な可読性、コメントの改善提案など
- **1 PR あたり最大 3 件**。それ以上はまとめて「その他軽微な点あり」とだけ書く
- formatter / linter で検出できるものは指摘しない(ツールに任せる)

## 人間レビュー必須の領域

| パス | 理由 | レビュアー |
| --- | --- | --- |
| `src/auth/**` | 認証・認可 | <owner> |
| `src/billing/**` | 課金 | <owner> |
| `infra/**` | 本番インフラ | <owner> |

## 運用

- 同じ指摘が 2 回出たら CLAUDE.md への追記を検討する
- 月次でレビュー結果を見直し、重要度付けと nit の量を調整する
