# slide-info-design

天野由貴『[情報デザインを意識したスライド作成入門](https://home.riise.hiroshima-u.ac.jp/~ten/slide_20240328.pdf)』(広島大学, 2024)をスキル化したプラグイン。

「伝えたい情報を、わかりやすく伝える」ために、視線の動き・配置・グラフ・フォント・色・全体構成の原則でスライドを作り、レビューする。

原著 7 章の「発表のしかた」(練習・話し方・時間厳守など)は一般的な心得で Claude が実行する作業ではないため、スキル化していない。スライドの作りに影響する会場条件(明るさ・スクリーン位置・縦横比)だけ `slide-design` に取り込んでいる。

## インストール

```text
/plugin marketplace add takashiski/my-skills
/plugin install slide-info-design@my-skills
```

## スキル

| スキル | 何をするか |
| --- | --- |
| `slide-design` | 原則に沿ってスライドを作る / 直す(pptx・Marp・HTML など形式は問わない) |
| `slide-review` | 既存スライドをチェックリスト(A〜G)でレビューし、ID 付きで改善案を出す |

参照資料は `skills/slide-design/references/` にまとめている(`checklist.md` / `charts.md` / `typography.md` / `color.md` / `copyright.md`)。

## 使い方の例

```text
研究発表 10 分のスライド構成を作って。テーマは〜
このスライド(slides.pptx)を情報デザインの観点でレビューして
明るい会場・低いスクリーンで発表するので、このスライドを調整して
```
