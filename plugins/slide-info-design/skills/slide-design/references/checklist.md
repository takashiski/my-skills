# スライドチェックリスト

出典: 天野由貴『情報デザインを意識したスライド作成入門』(CC BY-SA 4.0)の内容をチェック項目化したもの。
ID は `slide-review` の指摘で参照する。

## A. 全体構成
- [ ] A1 1 枚につき伝えたいことは 1 つ
- [ ] A2 1 枚あたり約 1 分で読み取れる情報量(詰め込んでいるなら分割する)
- [ ] A3 最後は「ご清聴ありがとうございました」ではなく、まとめスライド
- [ ] A4 タイトルのせいで図表が小さくなっていない(必要ならタイトルを外す)
- [ ] A5 縦横比が会場のプロジェクタ(16:9 / 4:3)に合っている

## B. 視線・配置
- [ ] B1 上から下、左から右の順で読める(フロー・手順も左→右)
- [ ] B2 要素が散らばっておらず、視線があちこちに飛ばない
- [ ] B3 四辺と要素間に余白がある。テキスト枠にも内部余白がある
- [ ] B4 端が揃っている(整列)
- [ ] B5 本文は左揃え(センタリングしていない)
- [ ] B6 関連する要素は近く、無関係な要素は離れている(グループ化)
- [ ] B7 大事なポイントが下端にない(低いスクリーンだと後方席から見えない)

## C. ノイズ
- [ ] C1 全ページのロゴがない(使うなら学外発表で表紙のみ)
- [ ] C2 内容と無関係なイラスト・飾りがない
- [ ] C3 塗りと枠線を同時に使っていない。不要な枠線(矢印の枠など)がない
- [ ] C4 強調は本当に大事な箇所だけ

## D. グラフ・表
- [ ] D1 目的に合ったグラフ種類(比較=棒、順位=横棒、時系列=折れ線、割合=円、傾向=レーダー、関係=散布図)
- [ ] D2 棒グラフの軸が 0 から始まる
- [ ] D3 棒の間隔: 多いとき棒幅の半分、少なくても 1:1 程度
- [ ] D4 横棒は長い順に上から、数値ラベル付き
- [ ] D5 折れ線の横軸は等間隔、縦軸の範囲が変化を誇張していない
- [ ] D6 円グラフは大→小、12 時開始、5〜6 個まで。ドーナツ型を使っていない
- [ ] D7 3D グラフを使っていない
- [ ] D8 グラデーション・影・光彩・立体なし。目盛線は最小限。枠線なし。マーカーは小さい
- [ ] D9 色数が少なく、強調したい項目だけ色を変えている
- [ ] D10 表: 原色なし、横罫線は見出し下と最下部のみ、テキスト左寄せ・数値右寄せ・半角

## E. フォント
- [ ] E1 28pt 以上(会場が広い・スクリーンが小さいならさらに大きく)
- [ ] E2 ゴシック体 / Sans-serif(明朝・Serif でない)。UD フォント推奨(BIZ UD ゴシック)
- [ ] E3 行間 1.1〜1.3 倍、字間は詰めすぎ・離しすぎなし
- [ ] E4 過度な文字装飾なし。強調は色・サイズ・太字
- [ ] E5 数値と単位があるとき単位を小さく

## F. 色
- [ ] F1 ベース / メイン / アクセントの 3 色程度に収まっている
- [ ] F2 面積比がおよそ 7:2:1
- [ ] F3 彩度が高すぎる色、明度が高すぎて薄い色を使っていない
- [ ] F4 トーンが揃っている
- [ ] F5 背景と文字のコントラストが十分(薄い背景に濃い文字 / 濃い背景に白文字)
- [ ] F6 CUD: 赤・ピンクと緑、ピンクと黄など見分けにくい組み合わせに頼っていない
- [ ] F7 明るい会場向けに図・グラフの色が十分濃い

## G. 権利
- [ ] G1 他人の著作物に出典を明示している
- [ ] G2 引用は区別性・主従関係・無改変を満たす
- [ ] G3 Web 公開・録画公開する場合、許諾が必要な素材を含んでいない
