# グラフと表

出典: 天野由貴『情報デザインを意識したスライド作成入門』3 章(CC BY-SA 4.0)。

グラフはデータや多くの情報を整理して見やすくするためのもの。グラフ自体にノイズがあると伝わりにくくなる。

## 種類の選び方

| 伝えたいこと | グラフ | ルール |
| --- | --- | --- |
| 絶対量の大小・数値の比較 | 縦棒グラフ | **縦軸は必ず 0 から**(省略すると面積とデータの比率が合わない。例: 30 と 40 が倍に見える)。棒の間隔は空けすぎない: 棒が多いとき棒幅の半分程度、少ないときでも 1:1 程度 |
| 同じ属性の順位付け / 項目数が多い / 項目名が長い | 横棒グラフ | **長い順に上から並べる**。大きさが比較しにくいので横に数値を書く |
| 時系列での増減 | 折れ線グラフ | 横軸の目盛は **一定間隔**。0 から始める必要はないが、縦軸の最大・最小を極端にせず、変化が誇張されない適切な範囲と余白を取る。マーカーは小さく |
| 全体に対する各項目の割合 | 円グラフ | **大きいセグメントから順に、12 時の位置から** 並べる。セグメントは **5〜6 個まで**。**ドーナツ型は中心角が見えず比較しにくいので避ける** |
| ある要素を構成する複数項目の比較・全体傾向 | レーダーチャート | 図形の大きさで全体傾向、形で偏り(例: 文系/理系科目)を示す |
| 項目の差(構成比の比較) | 帯グラフ | |
| 2 項目の間の関係 | 散布図 | |

## 3D グラフは使わない

- 3D にすると値が読み取れなくなる(例: 60 の棒が 60 に見えない)。
- 3D 円グラフは手前のセグメントが実際より大きく見え、誤解を与える。
- グラフの目的は「データや情報を正しく見やすく伝えること」。常に 2D にする。

## 装飾・ノイズを削る

- グラデーション、立体、影、光彩などの効果は付けない。
- **目盛線は減らす / なくす**(目に入ると人はその情報を読み取ろうとする)。
- **枠と塗りは両方要らない**。枠は情報を区切るためのものなのでグラフには向かない。枠線は外す。
- 既定の色とりどりの配色をそのまま使わない。色数を減らし、色相を揃える。
- **説明したい項目だけ色を変え、残りは同じ色** にすると、ポイントがわかりやすく統一感も出る。

## 表

- 原色を使わない(目にやさしくない)。
- 罫線をはっきり見せない。**横罫線は項目名の下と最下部だけ** で十分。縦罫線は不要。
- テキストはセル内で上下中央に配置し、枠線に近づけない。
- **テキストは左寄せ、数値は右寄せ**。数値は半角。
