# 著作権(スライドで他人の著作物を使うとき)

出典: 天野由貴『情報デザインを意識したスライド作成入門』附録(CC BY-SA 4.0)。日本の著作権法を前提とした概要であり、法的助言ではない。

他人の図表・写真・動画・文章を使うには、基本的に著作権者の許諾が必要。次の場合は許諾なく使える。

## (1) 授業での使用
- 授業での発表、課題提出、LMS への掲載などのための複製・公衆送信は OK。
- YouTube などを自分の PC に映してスクリーンに投影する「公の伝達」も OK。
- **出所(出典)の明示が必要**。

## (2) 著作権法上の「引用」
次の条件をすべて守る:
- 公表された著作物であること
- 「引用」であること
  - **区別性**: 引用箇所が明確(カギカッコ、区切り線など)
  - **主従関係**: 量的にも質的にも本文が「主」、引用が「従」
- 公正な慣行に合致し、引用の目的上正当な範囲内(著作権者に大きな経済的打撃を与えない量)
- **出所を明示する**
- **引用部分を改変しない**

## それ以外
- 自分で作る、利用条件に問題のない素材に差し替える。
- 特に次の「公衆送信」で (1)(2) に当たらないものは基本的に許諾が必要:
  - 他人の著作物を含む資料を SNS など誰でも見られる Web に上げる
  - 他人の著作物を含む発表を録画して動画を公開する
